# Inari — sistema básico de marca

## Composiciones

- `inari-logo-stacked.svg`: zorro con el nombre debajo, fondo transparente.
- `inari-logo-horizontal.svg`: zorro con el nombre a la derecha, fondo transparente.
- Las variantes `cream`, `dark` y `red` incorporan un fondo de alto contraste.

## Tipografía

El logotipo usa **Manrope ExtraBold (800)**, a una escala visual cercana a la del zorro y con el espaciado ajustado para mantener el carácter compacto del header del landing.

## Paleta

- Rojo Inari: `#b63d32`
- Tinta: `#241b1b`
- Crema: `#f6f1ea`
- Melocotón de acento: `#e7a27e`
- Blanco: `#ffffff`

El punto final de `inari.` se mantiene como acento cromático en todas las versiones.

La silueta incorpora un trazo fino del mismo color que el zorro para definir con sutileza el cuello y el pecho.
